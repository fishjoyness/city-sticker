## 故宫博物院 · `forbidden-city`

1. 南北中轴上的午门整体为明显的凹字形平面与正面展开轮廓。
2. 中央高台上是重檐庑殿顶主楼，两翼雁翅楼向左右伸展。
3. 两端各有重檐攒尖顶方亭，形成“五凤楼”般高低错落节奏。
4. 红墙、高台、黄琉璃瓦与五个门洞构成稳定色块和开口关系。

## 天坛 · `temple-of-heaven`

1. 祈年殿为三重圆形攒尖蓝琉璃瓦屋顶，层层收分。
2. 圆形殿身以红柱和深色门窗形成连续竖向节奏。
3. 主体立于多层圆形汉白玉台基，台阶朝前展开。
4. 保持严格中轴和“圆殿 + 圆台”的整体轮廓，不加入泛化宫殿。

## 颐和园 · `summer-palace`

1. 万寿山与昆明湖组成清晰的山水主体框架。
2. 佛香阁位于山前中轴制高处，为八面三层四重檐高阁。
3. 从湖岸经排云殿到佛香阁层层上升，形成竖向中轴。
4. 前景保留平静湖面与岸线，山体绿意包围暖黄、红、绿建筑色块。

## 八达岭长城 · `badaling-great-wall`

1. 宽阔、修整完整的砖石城墙沿陡峭山脊强烈起伏。
2. 城墙两侧连续垛口围合，远近透视清楚。
3. 多座方形砖敌楼分布在高点，门窗为拱券开口。
4. 可在近端保留关城券门与“北门锁钥”厚重城台轮廓，但不依赖匾额文字识别。

## 慕田峪长城 · `mutianyu-great-wall`

1. 长城贴合森林覆盖的锐利山脊，敌楼间距比八达岭视觉上更密。
2. 正关台由三座敌台并列连成一体，是首要区分锚点。
3. 城墙两侧均有垛口，并可见支城分岔与高低错落敌楼。
4. 以密林、陡坡和连体敌台构图区别于八达岭的开阔关城视图。

## 天安门 · `tiananmen-gate`

1. 巨大红色城台横向展开，正面五座拱形门洞按中轴排列。
2. 城台上为黄琉璃瓦重檐城楼，红柱与密集窗格形成水平节奏；城楼檐下中央国徽不可遗漏。
3. 红墙中央为画像，两侧固定标语牌；正面视角中左侧为“中华人民共和国万岁”，右侧为“世界人民大团结万岁”。
4. 广场北端国旗杆位于天安门正南、长安街以南，与城楼处于同一中轴；正式贴纸必须出现准确的五星红旗。
5. 天安门南侧七座外金水桥以中轴对称分布；简化时至少保留中央桥群、白石栏杆与水道关系。

## 天安门广场 · `tiananmen-square`

1. 采用北上南下的半俯视总平面表达四向位置，不用单一正面照片假装覆盖完整广场。
2. 北端为天安门；沿中轴由北向南依次为国旗杆、人民英雄纪念碑、毛主席纪念堂、正阳门城楼。
3. 西侧（画面左）为人民大会堂，东侧（画面右）为中国国家博物馆；两座长条形建筑围合广场东西边界。
4. 人民英雄纪念碑位于国旗杆以南、毛主席纪念堂以北，作为中央竖向焦点；国旗必须为准确的五星红旗。
5. 只保留浅色花岗岩广场、主要道路与少量绿地分区；不使用人群、节庆花坛或临时布置替代固定空间结构。

官方位置核对：[首都之窗：天安门广场](https://www.beijing.gov.cn/gate/big5/www.beijing.gov.cn/renwen/rwzyd/202011/t20201123_2142977.html)、[北京 12345 服务导图](https://map.beijing.gov.cn/place?placeId=60cb3c9ebd15ba1c65342d81)、[北京市文物局：北京中轴线](https://www.beijing.gov.cn/tsbj/sxym/202408/t20240802_3765724.html)。

## 北海公园 · `beihai-park`

1. 琼华岛位于湖面中央，岛上树木形成低圆山体。
2. 35.9 米白塔位于岛顶，是覆钵式白色塔身与金色塔刹组成的强识别轮廓。
3. 永安寺建筑与台阶沿岛坡层层上升，形成白塔下方中轴。
4. 前景保留北海水面与柔和倒影，白塔必须明显高于树林。

## 景山公园 · `jingshan-park`

1. 人工山脊上五亭横列，中峰万春亭位于最高点。
2. 万春亭为多层攒尖亭顶，黄／绿琉璃瓦与红柱构成中心色块。
3. 亭下山体为连续深绿树冠，整体呈对称展开的山丘轮廓。
4. 可在远景轻量提示中轴方向，但不把故宫画成第二主体。

## 雍和宫 · `yonghe-temple`

1. 南端三座牌楼组成入口序列，中央牌楼为三间四柱九楼。
2. 中轴寺院为红墙、红柱与黄琉璃瓦殿宇逐层深入。
3. 入口牌楼的多层屋顶、竖柱和横额形成密而清楚的节奏。
4. 不使用佛像或香火人群；以皇家寺院轴线和牌楼轮廓识别。

## 恭王府 · `prince-gongs-mansion`

1. 花园正门采用汉白玉西洋式拱门，是区别于普通王府门楼的核心锚点。
2. 拱门为浅色石材，中央圆拱配左右墙体与顶部卷草／石雕轮廓。
3. 背后轻量提示灰瓦园林屋顶与绿植，但不遮挡白石拱门。
4. 色彩保持汉白玉、灰瓦、暗红门与柔和绿，避免泛化宫殿金黄屋顶。

## 国家博物馆 · `national-museum-of-china`

1. 浅色石材立面极长、严格对称，中央体量略前凸。
2. 中央入口以高大方柱柱廊形成密集竖向节奏。
3. 两侧长翼水平延伸，窗列和檐口保持克制重复。
4. 前景仅保留宽阔台阶／平台，不添加展品或天安门作为第二主体。

## 鸟巢 · `birds-nest`

1. 主体为低矮巨大的椭圆碗状体育场，中央顶部开口明确。
2. 外立面由大量交错倾斜钢构件编织成不规则巢状网格。
3. 灰银钢架之间可见深红色内碗，形成内外层次。
4. 轮廓保持横向椭圆和两端收拢，不画成普通圆形体育馆。

## 水立方 · `water-cube`

1. 主体是简洁的横向长方体，四角清楚、体量完整。
2. 淡蓝半透明外立面由大小不一的泡状多边形膜单元覆盖。
3. 以蓝色块、白色膜线和轻微深浅变化表达“水泡”肌理，不做玻璃写实反射。
4. 与鸟巢分开成独立资产，不加入五环、文字或夜景灯效。

## 什刹海 · `shichahai`

1. 前海与后海的连续水面是主体，岸线自然展开。
2. 银锭桥为单孔白石拱桥，桥身低而横向，是核心近景锚点。
3. 湖岸保留灰瓦胡同屋顶、柳树和小尺度步行空间。
4. 远处可轻量提示西山起伏，避免酒吧招牌、船只和商业灯光主导。
