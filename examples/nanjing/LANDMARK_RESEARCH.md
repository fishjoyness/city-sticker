# 南京景点贴纸 — 地标研究与 Landmark Anchors

状态：ASSET LIBRARY / REVIEW  
研究访问日期：2026-08-30  
Style Version：`pen-travel-v0.1`

本文件补充南京正式 15 景中的 11 个缺项。已有并复用的南京博物院、鸡鸣寺、玄武湖、中山陵研究与资产保持不变。

## 01 明孝陵

Sources:

- 南京市中山陵园管理局：https://zschina.nanjing.gov.cn/fjms/jqjd/mxljq/
- 南京市中山陵园管理局（建筑形制）：https://zschina.nanjing.gov.cn/zszx/dtxx/202601/t20260112_5762212.html

Landmark Anchors:

1. 依山势展开的陵寝中轴与砖石方城高台。
2. 方城顶部的明楼和后方圆形宝顶关系。
3. 厚重红墙、券门与石阶形成的正面层次。
4. 神道石像生与林木只作为轻量上下文，不替代方城明楼主体。

## 02 南京总统府

Sources:

- 南京总统府景区官网：https://www.njztf.cn/jqgk/detail/297.html
- 南京总统府景点目录：https://www.njztf.cn/en/scenic_spots.html?data_id=864&sid=31

Landmark Anchors:

1. 1929 年建成的西式钢筋混凝土门楼作为主视图。
2. 浅色门楼横向展开，中部高起、三孔入口节奏明确。
3. 正面“总统府”门额位置只表现为结构区，不生成任何额外可读文字。
4. 两侧低墙与门前开阔关系保持克制，不画成普通欧式宅邸。

## 03 夫子庙

Sources:

- 南京夫子庙秦淮风光带官网：https://www.njfzm.net/index.htm
- 南京市秦淮区政府（夫子庙—秦淮景区）：https://www.njqh.gov.cn/dmqh/yzqh/qhhssylx/

Landmark Anchors:

1. 大成殿中轴、重檐屋顶和红墙院门。
2. 殿前秦淮河泮池与北岸石栏形成独特前景。
3. 对岸大照壁作为低矮横向背景，避免与秦淮河贴纸重复。
4. 江南庙学建筑群的层檐节奏，不简化成单座通用寺庙。

## 04 秦淮河

Sources:

- 南京市秦淮区政府（秦淮河水上游览线）：https://www.njqh.gov.cn/dmqh/yzqh/qhhssylx/
- 南京市政府（秦淮河文化与滨水廊道）：https://www.nanjing.gov.cn/zgnjsjb/jrtt/202311/t20231124_4105151.html

Landmark Anchors:

1. 内秦淮蜿蜒水面与两岸江南街屋形成横向河廊。
2. 一座低拱石桥跨水，桥洞倒影清楚。
3. 白墙灰瓦、暖色灯影和连续檐线，但不画成夜市海报。
4. 一艘小型画舫可作尺度参照，不能抢过河道轮廓。

## 05 老门东

Sources:

- 南京市地方志办公室：https://dfz.nanjing.gov.cn/gzdt/202412/t20241220_5037424.html
- 南京市地方志办公室：https://dfz.nanjing.gov.cn/gzdt/202411/t20241101_4998828.html

Landmark Anchors:

1. 入口高牌坊与笔直箍桶巷形成主透视。
2. 两侧青砖、小瓦、封火墙的老城南街屋轮廓。
3. 石板路向明城墙方向收束，保持历史街巷尺度。
4. 不依赖商铺招牌，不生成品牌或额外文字。

## 06 牛首山

Sources:

- 牛首山官方景区概况：https://tchinese.niushoushan.net/ScenicSpot.html
- 牛首山佛顶宫官方介绍：https://tchinese.niushoushan.net/TheTempleOfTheBuddha.html

Landmark Anchors:

1. 佛顶宫大穹顶如袈裟覆盖山体的非对称弧面。
2. 小穹顶由莲花宝座托起摩尼宝珠，位于大穹顶开口内。
3. 大小穹顶与牛首山双峰呼应，形成现代宗教建筑的独特剪影。
4. 佛顶塔可作为远侧竖向平衡，但不堆叠宗教图案与造像。

## 07 美龄宫

Sources:

- 南京市中山陵园管理局：https://zschina.nanjing.gov.cn/lyzx/202608/t20260821_5897747.html
- 南京市中山陵园管理局：https://zschina.nanjing.gov.cn/lyzx/202606/t20260612_5857511.html

Landmark Anchors:

1. 三层砖木混合主体和重檐歇山顶。
2. 绿色琉璃瓦、红柱与浅色墙体的中西合璧关系。
3. 二层环形阳台和连续栏杆形成水平节奏。
4. 建筑依山、林木包围，但不使用“项链航拍”噱头代替建筑。

## 08 阅江楼

Sources:

- 江苏省相关官方介绍：https://www.jsstb.gov.cn/view/202012/t20201210_12310746.htm

Landmark Anchors:

1. 狮子山巅的高耸楼阁与长江方向关系。
2. 外四层、暗三层形成的七层层檐轮廓。
3. 碧瓦、朱楹和密集上翘檐角的明式皇家建筑气质。
4. 山石基座和一小段江面用于说明临江位置。

## 09 中华门城堡

Sources:

- 南京市秦淮区政府：https://www.njqh.gov.cn/dmqh/yzqh/zhmwc/
- 南京市文化和旅游局：https://wlj.nanjing.gov.cn/ztzl/mcq/gzqk/202302/t20230228_3838766.html

Landmark Anchors:

1. 从略高斜俯视表现“目”字形三道内瓮城。
2. 四道券门南北贯通，厚重砖石城台清楚。
3. 主城台与两侧马道形成宽阔对称体量。
4. 藏兵洞只保留可读的拱洞节奏，不复原已毁城楼。

## 10 朝天宫

Sources:

- 南京市地方志办公室：https://dfz.nanjing.gov.cn/gzdt/202603/t20260317_5806832.html
- 南京市秦淮区政府：https://www.njqh.gov.cn/dmqh/yzqh/njsbwgctg/

Landmark Anchors:

1. 冶山之上的中轴宫殿式古建筑群。
2. 丹墙、黄瓦／碧瓦与高台石阶形成鲜明色块关系。
3. 棂星门牌坊式入口和后方大成殿层次。
4. 建筑群横向展开，避免画成单体通用寺院。

## 11 南京长江大桥

Sources:

- 南京市档案馆：https://dag.nanjing.gov.cn/dawh/dags/202404/t20240418_4211846.html
- 南京市公共工程建设中心：https://gjzx.nanjing.gov.cn/xmqk/cjdqwxgz/201612/t20161227_2242532.html

Landmark Anchors:

1. 上层公路、下层铁路的双层钢桁梁桥结构。
2. 长桥跨越宽阔长江，重复钢桁架形成强横向节奏。
3. 米黄色复式桥头堡高出桥面，顶端三面红旗剪影明确。
4. 多跨桥墩和引桥只保留必要数量，不能简化成普通现代斜拉桥。
